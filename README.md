# DKWIN — Android Gaming, Color Prediction, Crash & 1xBet Multi-Sports Platform

DKWIN is a native Android application built with Kotlin, Jetpack Compose, Material 3, and Room Database.

## Key Features
- **Zero Default Balance & Custom Amounts**: New user registrations start at `৳0.00` balance, minimum bet starts at `৳1`, and minimum deposit starts at `৳50` with custom amount inputs.
- **Win Go Color Prediction & Live Admin Control**: Synchronized `30s`, `1m`, `3m`, `5m` timers, configurable `1%–3%` auto service fee on every bet, real-time bet breakdown (Big/Small, Green/Red/Violet, Numbers 0–9) in the Admin Panel, and one-tap forced result or Auto-Balanced control.
- **4 Distinct Crash Plane Games & Thimbles**: Spribe Aviator, JetX Fighter, SpaceXY Rocket, and Crash Cricket X, plus the 3-Cup Thimbles game with Admin Panel win-rate and crash point controls.
- **JILI, Spribe & Pragmatic Slots**: JILI Super Ace, Golden Empire, Fortune Gems 2, Boxing King, Crazy 777, Fortune Tiger, Gates of Olympus, Sweet Bonanza, Mines, Dice, and Live Casino.
- **1xBet-Style Single & Multi-Bet Cricket/Sports**: Build accumulator slips across multiple BPL/ICC/IPL and Football matches, plus full Admin match management.
- **Idempotent Pending Deposits & Withdrawals**: Admin-configurable payment numbers, Send Money / Cash Out rules, editable 2–10 minute pending notice, and strictly locked idempotent approval/rejection.
- **Referral Commission & Telegram Support**: Admin-configurable referral commission percentages and live support chat with direct Telegram username integration.
